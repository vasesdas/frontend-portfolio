# Front-end Portfolio

Three responsive websites built with plain **HTML, CSS and JavaScript** — no frameworks, no build step.

| Project | Live demo | What it shows |
|---|---|---|
| **NOVA** — premium interior design studio | [nova-one-dun.vercel.app](https://nova-one-dun.vercel.app) | Elegant typography, image-heavy layouts, project filtering, full-screen lightbox, scroll animations |
| **Flowbase** — SaaS landing page | [flowbase-cyan.vercel.app](https://flowbase-cyan.vercel.app) | Dark/light theme, monthly/yearly pricing toggle, testimonial slider, FAQ accordion, animated counters |
| **Pulse** — e-commerce admin dashboard | [pulse-beta-kohl.vercel.app](https://pulse-beta-kohl.vercel.app) | Chart.js charts, sortable/searchable/paginated table, KPI cards, period switcher, collapsible sidebar |

## Highlights

- Fully responsive (mobile, tablet, desktop)
- Semantic, accessible markup (keyboard navigation, ARIA states, `prefers-reduced-motion`)
- Vanilla JavaScript: IntersectionObserver, CSS Grid/Flexbox, CSS custom properties

## Run locally

Open any `index.html` directly in a browser, or serve a folder:

```bash
python -m http.server --directory nova
```
